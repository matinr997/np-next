اتصال دیتابیس در آینده (MySQL روی Netafraz):
1) DirectAdmin > MySQL Management > Create new Database (نام/یوزر/پسورد)
2) از config.example.php یک کپی با نام config.php بسازید و مقادیر را پر کنید
3) فایل‌های PHP جدید را در همین پوشه قرار دهید (PHP 8.1+ در Select PHP Version)
4) تست: your-domain.ir/api/index.php باید JSON با ok:true برگرداند
